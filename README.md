## ⭐ Пет-проект: Fam AI — Семейный нутрициолог *(в разработке)*

**Чем полезен:** Личный сервис-«нутрициолог» для всей семьи: сам считает калории и БЖУ каждого, помнит диеты и аллергии, составляет меню на день и неделю, собирает список покупок и следит за складом продуктов. Помогает маме готовить один набор блюд на всех (а не по блюду на каждого), экономить на ингредиентах и не выходить за калорийность. Работает прямо в браузере как PWA и устанавливается на телефон.

**Архитектура:** React 19 + React Router 7 (SPA/PWA), сборка Vite 8, всё хранится в localStorage (серверного бэкенда нет), OCR — Tesseract.js, опциональная нейросеть через OpenAI-совместимый API (ProxyAPI), синхронизация магазинов через Playwright + управляемый Edge. Код разбит на модули: генераторы меню, движок диет, склад, статистика, парсеры рецептов, Telegram-интеграция. Покрыто набором юнит-тестов на `node:test`.

**Функции:**
- **Умное меню (AI):** чат-бот с двухуровневой генерацией — «Быстрое меню» по правилам (работает без интернета) и nextgen FAM через нейросеть (если подключён ключ). Ведёт диалог: семья → даты → пожелания → статистика за 14 дней → остатки склада → голосование в Telegram → черновик → результат.
- **Учёт диет и аллергий:** строгие правила — блюда, которые нельзя, никогда не предложит; 12+ диет, лечебные столы Певзнера №1–15, поддержка грудного вскармливания.
- **Оптимизация под семью:** ищет общее блюдо, подходящее всем; при конфликте диет ветвится; калории в пределах 90–100% нормы; большие порции тому, кому нужно больше.
- **Учёт склада и статистики:** предлагает блюда из остатков (минимизация продуктов), повторяет любимые рецепты семьи, но не чаще заданных лимитов (не более 40% повторов за 2 недели).
- **Понимание свободного текста:** «хочется рыбы», «без свинины», «без рыбы по вторникам» — пожелания разбираются автоматически.
- **База рецептов:** ~500 встроенных + 333 через Spoonacular + импорт по ссылке (food.ru, russianfood.com, карточки Перекрёстка/Пятёрочки) + импорт по фото (OCR).
- **Список покупок:** автогенерация по меню с категориями и вычитанием остатков склада.
- **Склад:** учёт сроков годности, списание, напоминания «продукт скоро испортится».
- **Чеки и расходы:** распознавание чеков, синхронизация с X5 Club (Пятёрочка) и Перекрёстком, статистика расходов по дням и членам семьи.
- **Статистика:** калории/БЖУ по каждому, закрытие прошедших дней, бэкап и экспорт всех данных.
- **Семья:** профили с ролями (повар/покупатель/голосующий), голосование за меню в Telegram, отправка меню семье.
- **Интерфейс:** тёмная/светлая тема, адаптивный дизайн, онбординг и встроенная справка — полностью на русском.

## 2. VPb01_Check_history_parser — «Чеки X5 Клуб → Excel-бюджет»

**Чем полезен:** Автономный инструмент для Windows, который превращает историю покупок X5 Клуба (Пятёрочка, Перекрёсток и другие сети X5 Group) в один файл `бюджет.xlsx` с живыми формулами и интерактивным дашбордом. Отвечает на вопрос «куда уходят деньги» без ручного сведения десятков файлов.

**Архитектура:** Python 3.12, Playwright (sync API) с подключением к системному Microsoft Edge через Chrome DevTools Protocol, openpyxl для Excel. Код разбит на конвейер: автоматизация браузера → разбор API заказов → категоризация → генерация книги.

**Функции:**
- автовход в аккаунт X5 (телефон + код из SMS), сессия переиспользуется;
- пресеты периода: 12/6/3/1 мес., 30/7 дней или свой диапазон дат;
- умная категоризация: `food / non-food / alcohol` + подкатегории еды (овощи, молочные, сыры, мясо и т. д.);
- всё в одном файле: чеки, позиции, сводка и дашборд;
- дашборд на нативных графиках Excel: расходы по дням, доли категорий, топ-продуктов, KPI-блок;
- каждое число — живая формула Excel (`SUMIF`, `COUNTIF`, ссылки), графики редактируются;
- кнопки запуска без макросов, `.gitignore` защищает личные данные.

- автоматическое создание таблиц и fallback прав через суперпользователя;
